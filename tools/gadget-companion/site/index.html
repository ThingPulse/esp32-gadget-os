Gadget Companion connects your Mac to your Gadget. See system stats and optional Codex usage, without keeping a terminal open.

Download for Apple siliconDownload for Intel Mac

Choose Apple silicon for an M-series Mac. Unsure? Open Apple menu → About This Mac.

macOS downloads are published with signed companion releases. If a download isn’t available yet, check the release page. Windows and Linux desktop apps are not available yet.

Get connected

  1. Open the download and drag Gadget Companion to Applications.
  2. Open Gadget Companion. Allow access to your local network when macOS asks.
  3. Keep your Mac and Gadget on the same Wi-Fi. On the Gadget, open Add apps → Pair computer, then tap Pair computer on the setup screen.
  4. Click Find my Gadget on your Mac and select it. Compare the six-digit code and confirm on the Gadget.
  5. Install System Monitor or Agent Usage from Add apps. Open it from Installed apps.

One pairing works for both apps. You can close the companion window; it keeps running in the menu bar. Start at login is optional.

System Monitor works on its own.

No Codex account is needed for CPU, memory, network, process and disk stats.

For Agent Usage, enable its switch in the companion. It checks for the Codex CLI and an existing sign-in. The Codex desktop app alone does not establish this prerequisite. See the Agent Usage setup guide.

Can’t connect?

Make sure the Gadget is powered on and your Mac is awake with Gadget Companion running. Check local network permission and avoid guest Wi-Fi. You can enter the Gadget’s IP address if automatic discovery doesn’t find it.

Pairing and updates currently use unencrypted HTTP on your trusted local network. Do not expose the companion ports to the internet.

Gadget Companion sends updates to your paired Gadget. It does not upload your system stats or Codex usage to ThingPulse.
