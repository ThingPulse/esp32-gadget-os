ThingPulse Resolve import test — verified in DaVinci Resolve 21 Free

Open ThingPulse-import-test.drp via the Project Manager's Import Project command.
Alternatively import ThingPulse-import-test.drt using File > Import > Timeline.
Keep the media directory beside these files. If moved, relink the media to that directory.

The timeline is 1920x1080 at 30fps, with two four-second shots on V1,
an editable Fusion Text+ overlay on V2, and music on A1.
To edit the title, select the V2 clip, open Fusion, select Text1, and change Styled Text.
The placeholder PNG is transparent; the visible lettering is generated by Text+.

Verified: OTIO import, two shot durations, separate music, text rendering,
DRT export and reimport into a clean project, and preservation of editable Text+.
The preview was rendered by Resolve and contains H.264 video plus stereo AAC audio.
This is a technical import test, not the final ad design or music edit.

Regeneration:
Run scripts/create-resolve-import-test.py in Python with Pillow and OpenTimelineIO.
Then open the separate project named ThingPulse Ad Import Test and run import-test.lua
using dofile('/absolute/path/to/import-test.lua') in Resolve's Lua console.
The OTIO file alone contains shots and music. The Lua step adds editable text.
